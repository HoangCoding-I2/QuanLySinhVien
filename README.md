# Dự Án Quản Lý Sinh Viên - Lập Trình Cho Thiết Bị Di Động (HOU)

Ứng dụng Android hoàn chỉnh cho đề tài **"Quản lý sinh viên"** (Báo cáo bài tập lớn Nhóm 2 - Đại học Mở Hà Nội).

## 🛠️ Công Nghệ Sử Dụng
- **Ngôn ngữ**: Java 17
- **Môi trường**: Android Studio
- **Hệ điều hành tối thiểu**: Android 8.0 (API 26+)
- **Cơ sở dữ liệu**: SQLite cục bộ
- **Giao diện**: XML Layout, tông màu Trắng - Xanh (`#1565C0` & `#FFFFFF`)

## 📂 Hướng dẫn chi tiết
Vui lòng xem file [HUONG_DAN_SU_DUNG_VA_BAO_VE_BTL.md](../HUONG_DAN_SU_DUNG_VA_BAO_VE_BTL.md) ở thư mục ngoài để xem:
- Hướng dẫn chạy và cài đặt APK
- Khớp nối 10 màn hình S01 - S10
- Kiến trúc CSDL SQLite
- Bộ câu hỏi vấn đáp khi bảo vệ Bài tập lớn.
